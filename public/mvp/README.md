# 道東トレイル快適度マップ MVP（地点CSV反映版）

静的 HTML / CSS / JavaScript で作成した、北海道東トレイル向けの動くMVPです。  
この版では、ユーザー提供の `hokkaido_east_trail_points_consolidated(1).csv` を取り込み、**625件の実地点データ**を表示しています。

## 取り込み済みデータ

- 総地点数：625件
- 主なカテゴリ：食事、宿泊、コンビニ、トイレ、水場、交通、町、危険エリア、駐車場、観光・見どころ、自販機
- 元CSV：`data/hokkaido_east_trail_points_consolidated.csv`
- 緯度・経度：CSV記載値を使用
- 確認済み：CSVの `確認済み` 列を反映

## 初期表示の考え方

食事・宿泊・町カテゴリは件数が多く地図が混雑しやすいため、初期表示ではOFFにしています。  
右側の「表示レイヤー」からONにすると表示できます。

## 4画面デモ構成

- `index.html`：アプリユーザー向けSP画面
- `admin.html`：観光協会向けPC管理画面
- `guide.html`：観光ガイド向けSP画面
- `partner.html`：スポンサー/保険会社向けPCダッシュボード

共通CSSは `css/style.css`、共通の地点データ・SOS仮データは `js/data.js` に整理しています。
各画面のヘッダーから相互リンクで画面遷移できます。

## 開き方

`index.html` をブラウザで開いてください。

地図・天気取得にはインターネット接続が必要です。  
ローカルでうまく表示されない場合は、以下のように簡易サーバーで開いてください。

```bash
cd hokkaido_trail_mvp_with_points
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000
```

## データを差し替える場所

`js/data.js` の `places` を編集すると、地点を追加・修正できます。  
SOSデモは同じファイルの `sosReports` を編集してください。  
今後は、CSVから `data.js` を自動生成するスクリプトを追加すると運用しやすくなります。

期待するCSV列：

```text
地点名 / カテゴリ / 緯度 / 経度 / 確認済み / 説明 / 注意メモ / Google Maps URL
```

## 快適度スコアの初期ロジック

現在はルールベースです。

```text
快適度 = 100
- 暑さ・湿度・UV・地表温度傾向
- 雨・風
- 水場・自販機・コンビニまでの距離
- 地形負荷
- ヒグマ注意
```

MVP段階では、正式な医学・防災指標ではなく「行動判断の目安」として表示しています。

## 表示が崩れる場合

地図タイルが北海道以外の場所にバラバラに表示される場合は、LeafletのCSSが読み込めていない可能性があります。
この版では `leaflet-fallback.css` を同梱しているため改善される想定です。

それでも表示が崩れる場合は、`index.html` を直接ダブルクリックせず、以下のようにローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで以下にアクセスします。

```text
http://localhost:8000
```

また、OpenStreetMapの地図画像を取得するため、インターネット接続が必要です。


## 公式KML連携について

今回アップロードされたKMLは、Google My Mapsへの `NetworkLink` を含む参照型KMLでした。
そのため、このMVPでは以下を実装しています。

- 公式ルート・モデルコース・ヒグマ出没状況・クマ対策ギア拠点のGoogle My Maps参照カード
- アプリ内ドロワーでのGoogle My Maps埋め込み表示
- アップロードKMLの同梱（`data/kml/`）

正確なルート線・注意区域ポリゴンをLeaflet上のレイヤーとして完全表示するには、Google My Mapsから「NetworkLinkではないKML/KMZ」または「GPX」を書き出して取り込む必要があります。

Google My MapsでKMLを書き出す場合は、可能であれば「データを最新に保つ / Keep data up to date」のチェックを外して、座標本体を含むKML/KMZを取得してください。
